A Markdown editor that gets out of your way.

MDPlus is a free, open-source Markdown editor for people who'd rather write than fiddle. No account. No subscription. No nag screens. Just you and your text.

What you actually get

Write first

The cursor is where you left it. The formatting is out of the way until you need it. No sidebars screaming for attention, no toolbars with forty buttons you'll never touch. Just the words and the syntax that does the work.

Your files, your disk

Everything saves locally as plain .md files — the kind any editor, any app, any human can open in twenty years. No proprietary format, no cloud lock-in, no "export" button holding your work hostage.

The shortcuts you already know

Bold, italic, headings, lists, links, tables, code blocks. If you've used Markdown before, you're already fluent. If you haven't, you'll be fluent by lunch.

Open source, for real

The whole thing lives on GitHub. Read the code, file a bug, open a pull request, or fork it and make it yours. That's not a marketing slogan — it's the actual license.

Why another Markdown editor?

Fair question. The Markdown editor market is crowded — there are bigger teams, shinier apps, and feature lists long enough to scroll. We're not trying to beat them.

We just wanted a small editor that opens fast, respects your files, doesn't want your email, and doesn't upsell you on features that should've been there in the first place. So we built one.

MDPlus is free. It's open source. That's the whole pitch.
